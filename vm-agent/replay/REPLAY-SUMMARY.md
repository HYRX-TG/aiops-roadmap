# 诊断能力四层丈量（2026-10-25 修订：注入方式口径修正）

同一个平台，两套大脑（规则 / DeepSeek-chat），三套数据集。
**这一版最重要的修订**：把"变更/操作事件怎么进入研判链"作为独立变量量了出来。

## 关键修订：分数取决于事件注入方式

之前的回放把结构化事件直接塞进 `alert.raw`，等于把答案递到研判链手里。
现在默认走**真实接入层**（`source=change_log / ops_audit` → 平台自己按 service 语义召回）。

| 数据集 | 注入方式 | 规则大脑 | 说明 |
|---|---|---|---|
| 留出集 | `--inject raw`（旧版） | **5/6** | 虚高：结构化事件直塞 alert.raw |
| 留出集 | `--inject ingest`（默认，诚实版） | **4/6** | 平台自己召回；语义召回修好后从 2/6 提升到 4/6 |
| 训练集 | `--inject raw` | 12/12 | 同样虚高 |
| 训练集 | `--inject ingest` | **12/12** | 数据层接通后，规则大脑确实能关联到变更 |

消融（同一份代码、干净库、只改输入）：

| 输入 | 留出集得分 |
|---|---|
| 只给告警文本 | 2/6 |
| + evidence 散文 | 2/6 |
| + 结构化 change_events（raw） | 5/6 |
| + change_log 走真实接入层（ingest） | 4/6（语义召回修好前是 2/6） |

**结论**：留出集的分数提升来自"数据层接通"而不是"大脑变聪明"。规则大脑本质仍是
**"把召回的时间线塞进剧本模板"**——它不会自己推理。这仍然有价值（真实 SRE 也是先查变更），
但**不能宣称"规则大脑具备泛化推理"**。

## 各数据集分数

| 数据集 | 规则大脑（ingest） | DeepSeek 大脑（raw 口径，历史数据） | 它在测什么 |
|---|---|---|---|
| 合成场景（第一轮） | 24/24 | — | 管子通不通（自欺：故障+答案都是我写的） |
| 真实事故·训练集 | **12/12** | 12/12 | 见过/参与过剧本编写的故障模式 |
| 真实事故·留出集 | **4/6** | 5/6（raw）/ 未重跑（ingest） | **没见过的故障怎么办** |
| 沙箱自愈实测 | **4/4** | 4/4（同链路） | 已认识的故障能不能真修好 |

> 留出集 4/6 的构成：Fastly 3 分（命中"关联近期部署"+"无灰度同步下发"两步），
> GitHub 1 分（未能关联 43 秒维护，也未识别脑裂）。**GitHub 那 0 命中就是结构性缺口**——
> 规则大脑不会从"复制拓扑异常"推到"网络分区导致双主"。

## DeepSeek 大脑的历史结论（需要按 ingest 口径重跑才算数）

历史记录（raw 口径）：留出集 5/6，GitHub 4/5 步命中（正确关联 43 秒网络维护 → 双主/脑裂 →
Orchestrator 放大 → 完整性优先），Fastly 拿到触发器但漏了 5/12 部署的潜在 bug。

**这个数字的局限**：raw 口径下 LLM 也拿到了结构化事件。要证明 LLM 有独立推理能力，
必须在 `--inject ingest` 下重跑（届时输入只有告警文本 + 平台自己召回的时间线）。
这件事**尚未做**，面试时应如实说明。

## 怎么读这些数字

**24/24（合成）是自欺**：错误信息里就写着答案。这轮的最大收获不是分数，是发现了"自己出题自己答"。

**训练集 12/12 不能当泛化**：三类剧本（运维变更/数据库/网络）是读完复盘才写的。

**留出集是唯一有意义的数字**：Fastly/GitHub 是写完剧本后才取来的。规则大脑 4/6、GitHub 0 命中——
说明剧本库是"记忆"不是"推理"。LLM 历史 5/6 有真推理成分（独立排查链），但口径需重跑确认。

**沙箱自愈 4/4 是另一件事**：它测的是"已知故障能不能真修好"，不是"未知故障能不能诊断"。
自愈口径已收紧（见 SELFHEAL-RESULTS）：`kill_noisy_neighbor` 因爆炸半径 node 超出默认自动上限，
现在需要人工审批，不再是"全自动"。

## 剩余的方法学问题（诚实清单）

1. **`change_events.detail` 仍带结论性措辞**（如"部署含未发现 bug 的软件"）。评分信号词会匹配到它。
   更严格的做法是只给中性事实（"部署了 1.4.3 版本"），让大脑自己判断是不是 bug。
2. **评分信号词是我定的**。虽然跑前固定，但仍有人为选择空间。
3. **样本只有 6 个事故**。统计意义有限，只能说明方向。
